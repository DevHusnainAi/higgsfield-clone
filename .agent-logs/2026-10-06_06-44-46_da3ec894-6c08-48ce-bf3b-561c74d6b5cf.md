- **Media type** is decided in this order:
  1. An explicit video word ("video", "clip", "timelapse") or a duration.
  2. An explicit image word ("photo", "illustration").
  3. A camera move, which implies video.
  4. Otherwise, image.
- **Camera moves:** 16 kinds. Each rule needs camera wording, so "frying pan", "tilt-shift" and "the 90s" don't trigger anything.
  - Negation works: "without zooming in" is ignored.
  - If two moves are mentioned, the first one in the prompt wins. When two matches start at the same spot, the longer one wins, so "zoom out" beats "zoom".
- **Aspect ratio:** only colon ratios count, such as "16:9". "2x3 grid" and "2/3 scale" are not read as ratios. Words also work: "tiktok reel" gives 9:16, "anamorphic" gives 21:9, and "square format" gives 1:1.

- **`matched`** records which words in the prompt set each field. Your chips can use it to show what the parser picked up versus what it assumed.
